ORA Library Frontend Add-ons

Copy into your React project:

1) Copy `src/api/library.api.js` into your project's `src/api/`
2) Copy `src/pages/library/` into your project's `src/pages/library/`
3) Add routes to your App.js (examples are inside docs in the original module).

API base used: REACT_APP_API_URL (default http://localhost:5000)
Backend endpoints: /api/library/...
